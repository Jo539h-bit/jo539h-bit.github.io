AI Customer Support Assistant for Nigerian SMEs

A reusable chatbot product that answers customers 24/7 from the business's own knowledge base — in English or Pidgin — captures leads, and hands angry or complex chats to a human. Each new client is just a config file and a knowledge base, no new code.

TypeScript Next.js Groq LLM API Anthropic Claude API Prisma + Postgres Railway n8n Telegram Bot API Webhooks (HMAC)
  • Embeds on any website with one <script> tag; channel-agnostic engine ready for WhatsApp Cloud API and Instagram DMs
  • Never invents prices or policies — answers only from the client's knowledge base, and says "let me get the team" when unsure
  • Knows business hours in Lagos time: after hours it still answers, captures the lead and says exactly when the team will follow up
  • Validates Nigerian numbers (080…, +234…), detects Pidgin, redacts card/PIN/OTP details and resists prompt injection
  • Human handoff with Telegram alert and live takeover from an admin dashboard (leads, CSV export, response-time stats)
  • Every lead is pushed by signed webhook into an n8n pipeline: AI scoring → Baserow CRM → Telegram → Google Calendar inspection → Resend email
  • Backed by 97 unit tests and a 24-conversation AI eval suite covering FAQs, Pidgin, angry customers, off-topic questions and prompt injection
